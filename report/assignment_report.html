Implementation summary

Four independent stages

  1. prepare.py downloads and saves raw NumPy arrays.
  2. preprocess.py normalizes and stratifies train/validation data.
  3. train.py builds Flatten → Dense/ReLU → Dropout → Dense/Softmax.
  4. evaluate.py writes JSON metrics and a confusion matrix.

Reproducibility

  • All hyperparameters come from params.yaml.
  • All four stages are wired through dvc.yaml.
  • Raw data, processed data, model, history and plot are DVC cached.
  • dvc.lock records every dependency/output hash.

Two-dot compares the two branch tips. Three-dot compares dev with the branches’ merge base, isolating work introduced on dev. They matched here because main was an ancestor after rebase.

A7 — Reset scenario

PS> git reset --soft HEAD~1 M scratch_reset.txt # still staged PS> git commit -m "restore second reset demo commit" PS> git reset --hard HEAD~1 HEAD is now at a9bb0a0 # commit and change discarded

Soft reset moved HEAD but retained the index. Hard reset moved HEAD and restored both index and working tree.
